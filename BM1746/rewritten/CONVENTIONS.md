# 转写约定 (CONVENTIONS) — BM1746 反编译产物 → 语义化 C

本文件是全部转写代理与读者的唯一规则来源。目标：把 `reversed/` 中 Ghidra 反编译的
~1,109 个函数转写为**语义严格等价、可读性优先**的 C 代码，按功能块合并文件。

> 语义等价 = 转写代码与反编译产物对相同输入产生相同的内存/寄存器效果。
> 允许恢复意图（循环、结构化控制流、命名常量），不允许改变行为。

---

## 1. 文件组织

- 一个功能块一个 `.c` 文件；大功能块按子主题拆分（如 `freq_pll_core.c` / `freq_pll_scan.c`）。
- 共享声明放 `rewritten/include/*.h`；模块内部函数放本文件顶部 `static` 前向声明区。
- **每个函数必须保留追溯横幅**：

```c
// === <语义名> === 原 FUN_000435e0 @ 0x000435e0
// 来源: reversed/cgminer/12_freq_pll/FUN_000435e0.c | 分类: 12_freq_pll
// 语义: 查频率表并整链广播 PLL 配置帧 (reg 0x0C)
```

## 2. 命名

- 命名事实源: `rewritten/name_map/<binary>.tsv`（阶段 1 冻结）。
  转写时**必须** `grep` 该文件取得所分配函数及全部被调函数的语义名。
- 命名优先级: `__func__` 精确匹配 > ARTIFACTS §4.3 / METHODOLOGY §6 锚点名 >
  日志串推断 > 分类前缀+序号（如 `nostrings_12_freq_pll_001`）。
- 函数名英文小写下划线，与原 `__func__` 一致优先；中文只出现在注释。
- 被调函数若 name_map 未收录（理论不应发生），用 `fun_<8位地址>` 占位并在注释标
  `/* 命名待补 */`，禁止自创名字。
- 局部变量按用法命名（`ret`、`i`、`buf`、`frame`、`pll_val`…），禁止保留 `uVar1/local_XX/acStack_XX`。
  允许出现 `v1, v2` 仅当多用途临时量且注释说明。

## 3. 类型

| Ghidra | 转写 | 判断依据 |
|---|---|---|
| `undefined4` 作整数 | `uint32_t` / `int`（有符号比较/打印 %d 用 int） | 用法 |
| `undefined4` 作布尔/小整数 | `int` | |
| `undefined1`/`byte` | `uint8_t` | |
| `undefined2` | `uint16_t` | |
| `uint`/`uint3` 等位域 | `uint32_t` + 显式掩码/移位，或注释保留位域语义 | |
| `int *param_1` 偏移寻址 | 尽量还原为结构体指针 + 字段名；布局不可知时保留 `(int*)` 指针算术并注释字节偏移 | 联合分析 |

- 不虚构结构体布局。指针目标未知时用 `void *` 或 `uint8_t *` + 注释。
- `extraout_r*`、`code *pcVar` 等伪变量必须消除（由实际返回/函数指针替代）。

## 4. 常量

- 寄存器码/魔数/阈值/表初值一律使用 `rewritten/include/bm1746_regs.h`、
  `fpga_axi.h` 中命名常量（来源均为已验证文档 `bm1746/BM1746_uart_register_ops.md`、
  `reversed/tables/`）。未收录常量保留十六进制并注释 `/* 语义待定 */`，**禁止臆造语义**。
- 已知全局数据（`DAT_00076b48` I2C 地址表、`DAT_00076b60` ticket mask 初值、
  `DAT_00076b74` 核心超时初值、频率表 `0x69204` 等）用头文件中 `g_` 常量/变量；
  其余未知 `DAT_xxx` 保留原名（如 `DAT_0009d6f8`）并在首次出现处注释 `/* 全局, 语义待定 */`。
- 字符串字面量原样保留（它们是日志/协议证据链，不得"翻译"）。
- `__func__` 自报名的字符串（如 `"set_frequency_chain"`）转写后天然由函数名提供，
  对应 `printf("%s: ...", __func__, ...)` 可直接写 `__func__`，但若该串出现在数据
  比较/表中则保留字面量。

## 5. 控制流

- 平凡 `goto`（if-else 链、循环 continue/break）必须结构化。
- 复杂 goto（错误清理链、状态机跳转）保留，但每个 `LAB_xxxx` 改为有语义的
  标签名并在注释说明来源标签。
- `switch` 保留 `switch`；Ghidra 的 `case` 序列若有跳表特征需注释原跳表位置。
- do-while(0)/for(;;) 按 Ghidra 原始结构还原，避免改变执行序。

## 6. 联合分析要求（寄存器/地址操作重点）

- 遇到 `base[...]`、I2C 值拼装、帧构造、位运算密集段时：**读被调函数与调用方源码**
  （在 `reversed/cgminer/<分类>/` 下按 `FUN_` 名查），对照
  `bm1746/BM1746_uart_register_ops.md` 的寄存器表与帧格式，在注释中写明
  字节序/位域语义（含 2026-11-20 修订后的正确语义：TX 前导 55 AA、RX AA 55、
  0x51=链广播写、0x41=带址读、byte[3]=0x09、ticket mask 出厂 0x10、核心超时 84000）。
- 构帧函数统一引用 `include/bm1746_regs.h` 的帧偏移宏（BM1746_FRAME_*）。

## 7. 函数体注释

- 横幅下 1-3 行中文语义说明（做什么、副作用、返回值含义）。
- 关键分支/魔数处行内注释；不影响阅读的平凡语句不加注释。
- 函数尾部覆盖率表由脚本自动生成（转写代理只需保证函数横幅规范）。

## 8. 禁止事项

- ❌ 修改 `reversed/` 下任何文件
- ❌ 省略函数（分配到的函数必须全部出现在输出中，哪怕 8 行的 getter）
- ❌ 引入原代码不存在的错误检查、参数校验、malloc/free、日志
- ❌ 使用原代码不存在的库调用（保留 `printf/snprintf/pthread_*` 等原有调用名）
- ❌ 把多函数合并成一个函数或拆分原函数

## 9. 输出自查清单（代理完成前逐项确认）

1. 分配清单中每个 `FUN_xxxxxxxx` 都能在输出文件找到 `// === ... === 原 FUN_xxxxxxxx`
2. `grep -n "uVar\|iVar\|local_\|acStack\|auStack\|LAB_\|extraout\|pcVar\|undefined"` 输出为空（或仅剩允许保留的 DAT_/FUN_ 占位）
3. 所有被调函数名与 `name_map` 一致
4. 文件末尾覆盖率表已生成（脚本 `tools/coverage.py` 或手工表）
